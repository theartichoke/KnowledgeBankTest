Google Sheets setup

Compatibility: This app is 2026.08.23.3 and requires bridge protocol KS-SYNC-4. The Test Connection button checks the installed bridge version before syncing.

  1. Create a Google Sheet that you want to use as the master question bank.
  2. Open Extensions → Apps Script.
  3. Replace the script with the bridge code supplied below (or download the included KnowledgeSpeedrunSheetBridge.gs file).
  4. Set SHEET_NAME if you want a particular tab name; otherwise leave it as KnowledgeBank.
  5. Save the script, then choose Deploy → New deployment → Web app. Google officially supports Apps Script web apps through doGet/doPost; the deployment screen lets you choose who the app executes as and who can access it. urlGoogle's Apps Script web-app documentationhttps://developers.google.com/apps-script/guides/web
  6. For a personal sheet, use an access setting that lets your app reach the deployment. If Google asks you to authorize the script, authorize it for the Google account that owns the sheet.
  7. Copy the deployed /exec URL into the Google Sheets tab above.
  8. Press Test Connection, then Pull From Google Sheet if the sheet already contains questions, or Push Local Questions if the app is currently the version you want to make the master.

The bridge uses the spreadsheet itself as the readable database: one question per row, with the same columns used by the app's CSV format. Google Apps Script supports reading/writing spreadsheet ranges from a script. urlGoogle Apps Script Spreadsheet Range documentationhttps://developers.google.com/apps-script/reference/spreadsheet/range

Manual CSV fallback

  1. Press Export Questions (CSV).
  2. Open the CSV in Google Sheets.
  3. Edit/add/delete rows as desired.
  4. Download the sheet as CSV.
  5. Use Import Questions (CSV) in the app.
